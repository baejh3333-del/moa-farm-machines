# 실제 모델 기반 목업 사양

확인일: 2026-11-07. `src/data/machine-specifications.js`에 모델별 원문 링크, 확인 값, 미확인 항목을 저장한다. 기존 100개 매물 ID와 거래 조건을 유지하면서 실제 모델 12종으로 통일했다. 같은 모델의 여러 매물은 동일 사양을 참조한다.

| 기종 | 실제 모델 | 근거 |
| --- | --- | --- |
| 관리기 | 아세아텍 AMC-900 | 제조사 AMC-900 제품표 |
| 트랙터 | 대동 DK450HSRQ5, DK550HSRQ5, DK600HSRQ5 | 대동 DK 상세 형식별 제원 |
| 휴립피복기 | 아세아텍 FM-120N | 제조사 사양 및 880/900/1000 부착 가능 목록 |
| 정식기 | 얀마 PH1,R | 일본 R 사양. 기존 A 및 WR 수치와 혼합하지 않음 |
| 이앙기 | 대동 DRP60D | 디젤 6조식 사양 |
| 분무기 | 혼다 WJR2525T | 에콰도르 공개 사양. 국내 사양 동일성 미확인 |
| 감자 파종기 | 강농 KG-PH9000 | 제조사 제품 설명 및 형식명 |
| 콤바인 | 대동 DXM73GF5 | 제조사 제품 설명 및 오류 없는 제원 행 |
| 감자 수확기 | 두루기계통상 DR-950AN | 한국농기계공업협동조합 2026 목록집 인쇄 115쪽, 군산시 공개본 |
| 운반차 | 대동 Mechron2450 | 제조사 2450 열. 2460 수치와 혼합하지 않음 |

## 데이터 경계

- 실제 모델 사양과 매물 정보를 구분한다. 가격, 위치, 예약, 점검일, 상태, 권장 면적, 작물/작업 검색 태그는 기존 시연 설정이며 제조사 보증치나 실제 재고가 아니다.
- 작업기 포함 주장을 없애고 본체/작업기 단품/독립 구동을 명시한다. 트랙터 단품에 로터리가 실제 포함된 것으로 해석하면 안 된다.
- PS, HP, kW를 혼용하지 않는다. 제조사가 단순히 '마력'으로 안내한 적용 출력은 원문 단위와 `basis: unspecified`를 보존한다.
- 홈페이지에서 확인되지 않은 히치 카테고리, 핀 직경, PTO 스플라인 및 승강력은 null이다. null끼리 같다고 호환으로 처리하지 않는다.
- FM-120N 중량의 단위가 mm로 기재되어 채택하지 않았다. DXM73GF5 표는 중량 이후 항목 값이 어긋나 있어 그 구간의 수치를 채택하지 않았다.
- DR-950AN 유통자료는 35마력, 2026 목록은 43마력 이상이다. 최신 목록의 43을 기록하되 연식과 단위 확인이 필요하다.

## 호환 판정 기반

`checkModelCompatibility(powerUnitId, implementId)`는 제조사가 명시한 AMC-900 + FM-120N만 `compatible`로 판정한다. 본체 종류가 다르면 `incompatible`, 같은 종류라도 세부 연결 확인이 안 되면 `check`, 부착 작업기가 아니면 `notApplicable`이다. compatible은 제조사 모델상 부착 가능을 의미하며 개별 중고 장비의 개조/연식/부품 상태 확인을 대체하지 않는다.

이 변경은 사양 카탈로그, 100건 시드/API 연결, 상세 사양 표시, 판정 함수까지 포함한다. 보유 농기계 등록 화면과 세트 예약/자동 추천 화면은 아직 추가하지 않았다.

## 기존 DB

초기화 시 알려진 시드 ID의 모델 관련 표시 필드만 갱신한다. 가격, 예약, 상태, 소유 설정은 덮어쓰지 않는다. 사양 객체는 모델 카탈로그에서 API 응답에 합쳐 제공한다. 실행 중 서버는 재시작해야 새 카탈로그가 반영된다.
