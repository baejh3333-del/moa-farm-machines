# 실제 서버용 AI 추천 에이전트 설정

이 디렉터리는 PRD의 F05와 8장에 맞춘 eve 에이전트다. 현재 HTML 목업과 연결되어 있지 않다. 모델은 입력을 구조화하고 질문과 설명을 담당하며, 서버가 검수 콘텐츠와 실제 게시글 필터링을 담당한다.

기본 파일·셸·웹 도구와 자체 하위 에이전트 호출은 꺼 두었다. 허용된 도구는 아래의 읽기 전용 조회 두 개다.

## 서버 연결 계약

서버는 `FARM_API_BASE_URL`의 origin에 인증된 읽기 전용 엔드포인트를 제공한다. `FARM_AGENT_API_TOKEN`은 서버 환경에만 둔다. 에이전트에 게시글 수정·예약 승인 권한을 주지 않는다.

- `GET /internal/agent/crop-guidance?cropId=...&region=...`: `get_crop_guidance.ts`의 `guidance` 스키마. 지원하지 않는 작물은 404.
- `GET /internal/agent/listings?...`: `search_listings.ts`의 `results` 스키마. 공개 게시글만 반환한다. 서버에서 작물·단계·기종 호환, 기계 상태, 거래 상태, 지역, 대여 기간과 기존 승인 예약의 겹침을 검사하고 최대 3개를 적합성→거리→난이도→가격 순으로 정렬한다. 정확한 주소·연락처는 반환하지 않는다.
- `asOf`와 `updatedAt`은 ISO 8601 시각, 날짜는 `YYYY-MM-DD`, 면적은 ㎡, 거리는 직선거리 km, 가격은 원이다. `priceUnit`은 대여 `day`, 구매 `total`이다.
- 대여 요청·구매 채팅 시작 API는 에이전트의 검색 결과를 신뢰하지 않고 요청 순간 서버에서 상태와 예약 충돌을 다시 검사해야 한다.

## 로컬 준비

Node.js 24 이상에서 `npm install` 후 `.env.example`을 참고해 서버 환경 변수를 설정한다. `npm run agent:build`로 구성을 검증하고 `npm run agent:dev`로 대화형 개발을 시작한다. 모델 인증은 eve의 `/login` 또는 배포 환경의 Vercel AI Gateway로 설정한다. 실제 서버 API가 아직 없으므로 도구 호출은 연결 전까지 실패한다.

실제 파일럿 전에는 인증된 사용자 세션을 서버와 연결하고, 게시글·예약·채팅의 접근 권한을 서버에서 검증해야 한다. 데모의 구매자/판매자 버튼을 인증으로 사용하지 않는다.
